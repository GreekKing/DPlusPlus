# D++

> Easy to start. Hard to outgrow.

D++ is a simple, powerful programming language designed to be easy to learn without taking away low-level power.

## Why D++?

D++ is designed around one idea:

**The computer should handle the boring complexity. The programmer should focus on building things.**

D++ aims to combine:

- Simple, readable syntax
- Native performance
- Easy learning curve
- Low-level control when needed
- Game development
- System programming
- Networking
- Advanced mathematics
- C and Assembly interoperability
